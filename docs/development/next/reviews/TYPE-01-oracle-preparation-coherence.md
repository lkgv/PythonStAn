# Oracle preparation coherence

The independent low-contract review found that a never-used prepared token could erase newer live oracle state. New negative controls reproduced this for fact growth, topology-only changes, calls, subscriptions and bind operations. A real host counterexample also showed why commit-time rejection alone is insufficient: the host had already published its alias epoch and roots.

Preparation now captures real producer and arena stamps before callbacks. It owns and charges mapping/alias snapshot visits, rechecks cheap stamps immediately after each charge callback, and rejects source mutation before another clone or iterator advance. The concrete token implements the lower protocol's real `validate()` method. The host calls this immediately before publishing any arena/root state. Commit allows the unchanged captured source arena or exactly the owned prepared quotient at the next epoch, while every other producer/identity/policy stamp must remain unchanged. Already-used commit remains idempotent.

The original 10 negative controls failed before the fix. A late-callback case separately exposed collection-resize RuntimeError before the immediate recheck was added. All 15 coherence controls now pass, including the actual host ordering case and both valid publication branches. The affected low/oracle/composition matrix passes 93 tests. The three owned files have zero ordinary-import strict diagnostics, pass Ruff/format checks, and retain 311 imported diagnostics in six dependency files. Owned and integration hashes remained stable during checks; exact evidence is under `artifacts/next/evidence/N4-TYPE-01/oracle-preparation-coherence/`.

This follow-on disposition is separate from earlier low-contract and dictionary acceptance. The actual host transaction is serialized; arbitrary backing-dictionary mutation and unsynchronized concurrency are outside that transaction API. Arena validation covers object aliases and epoch, not every arena field. This does not qualify a complete cost ledger, parent TYPE card or release. No baseline or frozen expected results were reset.
