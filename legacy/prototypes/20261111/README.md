# Historical PythonStAn prototypes

These17 original files are preserved byte-for-byte outside the installable Python package after a static import/dynamic-literal audit found no active consumers. They are unsupported historical prototypes, some with missing old imports or external dependencies. They do not implement any current analysis strategy and are not compatibility shims. The source history and archive preserve their provenance; active functionality resides in the maintained engines and explicit compatibility layer.
